PromptOps privacy

This extension composes locally, only after you select text and invoke it. There is no automatic typing capture, network transmission, shared API key, or automatic send.

Password, payment and other sensitive fields are excluded. Rich editors may require copying and pasting manually. Review each result before confirming replacement.

Existing server API integrations remain in the repository, but this extension no longer uses stored API keys. Legacy stored values are not read or sent.
